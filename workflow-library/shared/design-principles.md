# Agent 设计原则与轻量检查

当前用户要求优先。本库用于忠实于材料的制作，不额外审查研究结论的科学严谨性。准确文案、材料身份、内容关系和可编辑性保持完整。

## 优先顺序

忠实于材料与信息完整 → 内容关系 → 可读性 → 跨页一致与空间组织 → 视觉与装饰。

信息多时先调整分组、图文比例和空间，不因图片数量增加而自动减少分点、删条件或把必要内容移出页面。生成阶段遇到问题尽量本步定位并修正，不到下一阶段开头才用审美检查阻断任务。

## 内容与图文关系

主标题恒为最高项；副标题可增加或删除，仅附属于主标题，不与正文、图片参与并列。实际小标题统领所属正文或多条正文并保持对齐。编辑文本标签不是上屏小标题，不能据此补造文案。

有并列信息就独立分点，多层嵌套表达真实归属；各段、各分点、小标题与正文保持独立文本对象，不能合并成长文本框。关键结论用一句完整的话，其余可用短语；数值保留条件、单位和比较口径。

逐页积极插入符合内容的材料图片，允许互补多图，不放无关图片凑数。先按全篇分配，避免重复使用：同页同一图片仅一次，内容相同但文件名或材料id不同也视为重复；跨页优先不同且合适的图片，只在明确要求或前后对照、局部讲解确有必要时复用。不为去重硬塞无关图，不删已确认文案或擅改用户选图；共用主题底图不受此限制。封面和目录默认不另配内容图片，但可使用03生成的主题底图。每张图片仅有一个图片标题或一条图注，二选一，不同时存在、不重复补写。图片标题直接从属于图片并置于上方，字级或承载与分组小标题区分；图注在图片上方或下方。内部编辑标签不算图片标题。

规划阶段内部估计图片最小可读尺寸与文字空间，不把估计数展示给用户，不用宽高比匹配图片身份。尺寸估计不能导致自动删分点；图片较多或较大时先优化布局、层级和分组。

### 分块说明与风格要求的分工

适合内容时必须采用有表达作用的特殊分块、特殊承载与图文组合，用疏密和尺度建立重点；只给粗略的单页创意方向，局部形状、装饰与组合由生图模型发挥。不能改变内容关系或挤压完整文案。可按语义用箭形表现流程、金字塔表现分级、波浪表现历程、斜切组织对照与图文分隔、弧线串联历程或围合中心，逐页结合文段关系、文字量及图片空间判断；适合的创意方向必须落实到设计稿与最终提示词，多个方向适合时选表达作用最强的一种，不写成可选或探索建议。确实不适合时采用常规分区并在设计稿简述原因。单页只选适合的粗略方向，不堆砌例子。先依据文段理解真实流程、递进、因果或回指反馈，用自然语言说明在哪些内容之间添加箭头、表达什么联系，不另设起止点登记；并列不加箭头。最终提示词的视觉关系项仅给具体绘图指令（例如从某段文案用直箭头指向另一段文案），仅附简短的实际联系含义，不泛泛解释逻辑、不罗列全部箭头形态、不照贴这条编写规则，不新增形状检查门槛。

特殊分块是设计要求，不是检查项，不设过半或固定页数配额，普通横带、网格与装饰不触发失败。版式库只是样例，可以原创，不机械按页码轮换。最终提示词的风格要求必须包含简短的创意设计，按本页实际关系落实特殊分块与图文组合、疏密和尺度变化；不照贴编写规则，不机械堆全套形态。完整预设保留原分块与承载。排版项概述内容如何组织，不重复创意段或反复展开逐框细节。

### 同风格底图的核心底色与文字预留

同方向封面、目录、内容背景使用同一核心底色。仅封面必须写明具象主体：以PPT核心对象为依据的艺术形象及一两项可画特征，不要求写实复刻；可平面或立体表现，不能用无特征普通物件、泛化雕塑、抽象概念或氛围代替。内容页背景不要求主体。艺术意象必须符合主题、贯穿全篇材料共同主线，不只代表局部小节或案例。封面与目录在形态、视角或视觉效果上至少一项明显不同，适用于任何风格；各方向均围绕PPT实际介绍的核心对象，不以无关物件换风格。可有少量主题点缀，不形成多个竞争主体。

封面主体占据视觉区，标题区连续留白；主体与文字留白的边界线仅作提示。目录文字区留空且无文本框、条目或分框；内容背景中央大片留空，仅低对比边角主题元素，不预画分栏、卡片和分隔线。底图不含文字、编号、图注、文本框或图片占位框。

### 底图生成的复杂度与视觉主次

简约平面与写实／立体是03的独立选项，主体选取要求相同，均须明确表现符合主题、贯穿全篇的单个主体对象，不限制简约主体必须平面化。简约的背景和装饰采用平面色块与点阵，避免复杂渐变、光影；页内文字无渐变、不用书法体，色块与文本框避免渐变。风格规则用于内部规划，实际提示词仅写简短的绘画要求，不照抄规范段落。简约优先借用适合主题的预设配色，可保留平面设计；完整继承预设与仅借配色区分处理。主体用简短艺术意象描述，不扩写结构或参数；生图提示词不写风格名、登记依据或通用美学口号。

### 学术与创新创业场景的文本框处理

按实际主题选择设计，不因“汇报”“答辩”机械套用竞赛舞台效果。学术用途中的文字承载可采用平整填充或无框，尽量不要使用渐变；必要色块与局部背景保持层次，无框文字不强制加底。采用完整预设时按其明确设计与用户要求取舍，不对所有页面套统一卡片。

可读性按文字所在局部底色（含文本框填充）判断：深区浅字、浅区深字，强调色同样清晰。以上是内部设计和看图参考，实际提示词只列页面可用的大致颜色，不逐类指定文字颜色，也不附加这些通用原句。

## Agent 轻量检查

底图生成后不自动审美检查或自动修正。整页预览生成后，在本步记录内容遗漏、错图、严重遮挡、不可读或关系错误；轻微配色、装饰、对齐或留白作为建议。特殊分块、academic_fill、restrained_decoration不单独构成否决项。

占位框比例重点检查：与所登记图片比例偏差超过2%时，先对AI底稿图生图修正，最多两次，修正只发当前问题；仍有偏差也贴回原图并保留记录。原图按占位框宽高完整铺满，不限制显示比例与拉伸幅度，不回退等比留边，不裁切原件。

原图贴回后自动调整只改变图片位置和大小，不修改底图、文字、配色或其他对象；具体框定位、身份映射、合成与记录按[预览契约](preview-contract.md)。检查有问题仍可选择图片、明确确认后继续05；修订尽量留在产生问题的当前步骤。

## 章节进度条

页顶进度条全篇共用4、5或6个语义章节段，不是一页一个点。01提供章节名与段数，材料理解后自动建议，用户可直接修改；手动编辑后重新理解材料不覆盖。逐页规划为每页选择所属章节，多页可共用同段，不为凑段数增页或强加正文小标题。预览和PPT重建沿用同一套名称及当前章节，封面和目录不显示。

## 原生渐变重建

预览中已有的文字与简单色块渐变，使用 PowerPoint 原生渐变填充，记录色标、位置、方向与每色标透明度，保持文字和形状独立可编辑。文字渐变作用于字形，不给无框文字额外加底框；不将这些渐变转成 SVG、位图或纯色。复杂图标、几何及纹理继续按 SVG／抠图口径重建；登记底图本身保持原图。此项规定还原方法，不要求额外添加渐变设计。


封面主体是核心主题的艺术化表达，不要求写实复刻。先理解材料对象与特有关系或能力，再形成一个鲜明可画的艺术形象；不默认使用单张页面、玻璃面板、通用界面或普通物件。材质不代替主体特征；文稿与软件题材可将其特有能力作视觉转译，不机械复刻空白窗口，也不把同一文稿图层模板套给所有题材。实际提示词只保留所选形象和一两项可画特征，不出现“登记原图”“原生形状”“仅表现框位”等程序术语，不预画空文本框或图片占位框。目录与内容背景不继承封面的主体限定。
