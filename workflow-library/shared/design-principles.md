# 设计判断与检查提示

本文件是各阶段设计决策的统一依据。设计稿记录本项目的选择，不复制整份规范；阶段文件只补充各自的操作要求。用户明确要求优先于默认建议，事实准确、原件身份与交付可编辑性仍须保持。

## 优先顺序

1. **事实与表达准确**：保留必要条件、比较口径、证据和结论，视觉关系不得暗示不存在的因果或层级。
2. **内容逻辑与可读性**：先确定主要观点、证据组织、阅读顺序和文字层级；正文、图表与关键信息清楚可读，不能用装饰或高密度目标牺牲阅读。
3. **跨页一致与空间组织**：统一对齐、间距、配色语义与导航；同类内容可以复用同一版式。
4. **视觉表现与装饰**：在前三项满足后选择分块形态、框形、主视觉、背景与特效。

冲突时按以上顺序取舍。信息多时先精简赘述、重新分组或拆页；留白合理时保留，不用缩小字号、增加框形或补图来凑密度。

## 用户明确要求与条件性设计建议

特殊分块严格过半、每页有相关配图、并列段落拆分为独立可编辑文本框属于用户明确要求；并列段落须有统领整组的小标题；具体分块形态、框形与特效按内容关系选择。

- **分块**：先判断流程、对比、层级、并列或中心与支撑关系。在符合内容逻辑、保持可读性的前提下，使用特殊分块的页面数必须严格大于全篇正式总页数的一半，并尽可能多使用；适配时优先采用特殊分块，让尽可能多的页面使用有助于表达的特殊形态。逐页说明形态如何服务内容关系；不能为增加数量而暗示不存在的层级、因果或中心关系，也不能牺牲阅读。常规分块更适合内容时可保留，但整套须满足特殊分块页数过半。总页数 N 取 content.json 的全部正式页面（含封面、目录、章节页、内容页与致谢页），最少需 floor(N/2)+1 页；同一页采用多种特殊分块仍只计一页，横带与四宫格不计作特殊分块，单纯装饰背景也不计。特殊分块参考图仅作结构启发，不要求严格按照参考图生成页面；可按内容关系、文字体量和阅读顺序调整分区数量、比例、方向、曲率、顶点／圆心位置及组合方式。以本页设计稿的实际选择为准，不照抄参考图的黑线、粗边框或具体几何。积极使用斜切、弧线以外的创意特殊分块，不把这两种作为默认重复方案。结合内容主动探索扇形、同心圆、波浪、金字塔、圆形放射、左圆右栏、六边形／蜂窝及它们的变体或组合。整套复核时检查是否过度依赖斜切和弧线，对适合其他形态的页面主动改进；变化应来自内容关系与空间组织，不靠换色、镜像或堆装饰凑数。同类内容可复用有效结构，不设各形态的固定数量配额。
- **文本框**：由语义分组和阅读需要决定是否套框。长正文通常适合矩形或无框排布；短标签可采用胶囊、圆形等。避免大量圆角矩形卡片并列或整页铺满重复卡片，不默认给每段文字套一个可见圆角框；优先按内容关系采用清楚的分区、无框列表、对照、步骤或特殊分块。可以使用少量圆角框，合理比较场景也可保持同级一致，不设固定数量阈值，不为避开圆角矩形而换成另一种形状继续堆卡片。无框文字或共用分区底色中的各段仍为独立可编辑文本对象；不合并并列段落。同级保持一致的层级与视觉语言，装饰可省略。并列文本框可按内容需要采用“小标题＋正文”结构：每个框的小标题概括该框内容，同组小标题的层级、位置、对齐和样式一致，正文与小标题有清楚的层级差异；无助于理解时可省略小标题。框内小标题不同于整组的分区标题，不要求每组同时具备两者。
- **要点**：多段并列文字必须逐段拆成子列表，每段对应独立可编辑文本框，并有一个准确、简短的小标题统领整组分点；已有页面或分区标题确实概括该组时可直接复用，不重复加标题。统领标题须作为定稿文字登记，各段仍独立排布；逐框的小标题按内容需要选择。单段内部连续说明可保留在同一文本框。
- **配图**：每一页都必须有至少一处与本页内容相关、清晰可辨的配图，包括封面、目录、章节页、内容页和致谢页。可用登记照片、数据图、图表、机理图、示意图或主题主视觉；单纯底色、纹理、分区色块、边框与导航装饰不算配图。优先采用登记原件；缺少非事实性机理图、示意图或主题图时可生成补充，事实图片缺口必须登记，不能生图伪造证据。配图应服务内容并保持可读性，不为有图而堆放无关素材。
- **主视觉**：按标题长度、阅读方向和主题安排左、右、中央或通栏构图。标题在左时可采用“主体偏右、左侧干净”；标题在右时可镜像，短标题也可居中。平面、摄影感或 3D 表现按主题选择，不固定为现实 3D。
- **背景与素材**：成组大图是候选和风格参考，不因生成过就必须进入成品。背景可用原生纯色、渐变或已登记且实际采用的图像。封面、目录和内容页按表达需要采用对应候选图；只重建已批准画面采用的素材。补充图标或插画要有用途，避免零碎堆砌。
- **边缘处理**：照片、截图和数据图可保留矩形原边，保证信息完整；独立主体需要融入背景时再抠边、羽化或套遮罩。边界贴合、弧形排列和装饰位置是可选手法，不得妨碍文字与事实图阅读。
- **框高与底色**：框高以内容和分组关系为准；短文本通常不需要高框，比较卡片为保持共同尺度可以等高。采用有填充的文本框时，框底与背景主色应有可辨认的色差，并核对所在区域的实际背景对比，让框体层次清楚；这里比较填充色而非描边色，不能只靠描边代替框底色差。优先用协调的邻近色或明度变化，复杂背景按框所在区域判断，不以整页平均色代替。填充色、描边色分别记录，不设固定色差阈值；需要更强色差才能清楚分组时允许使用，文字对比和可读性优先。无填充或无框文字按文字与背景的可读性检查。深色阅读区必须使用浅色文字，浅色阅读区使用深色文字；以局部实际底色为准，强调色也须清晰可读。生图提示词仅概述色系和明暗，精确色值留在内部风格登记与重建数据中。

较充分的信息密度、页内逻辑与可选文字配色建议按[信息密度与文字配色](content-density-and-text-color.md)执行，用户明确风格可覆盖默认值。

## 数值只用于触发复看

以下是诊断起点，不是版式通过条件。命中提示时检查真实画面：是否内容不足、阅读受阻、主体被裁、背景干扰或层级不清。合理的留白、图文比例、字号与配色可以保留，在现有 review／qa-review.json 的 notes 中简述依据；无需为偏离建议数值另行申请批准，也不按警告数量自动否决。

| 检查主题 | 参考起点 | 复看重点 |
|---|---|---|
| 内容区占比 | 宽约 72%、高约 62%、面积约 45% | 是否充分支持本页观点；封面、章节页、单结论页可更疏朗 |
| 连续留白 | 约 18%–28% 或多个空白分区 | 是否帮助分组、突出结论，而非遗漏内容 |
| 主视觉占比 | 封面约 20%–60%；目录约 10% | 主体是否清楚、文字是否有足够空间；目录页也必须有与主题相关的配图 |
| 背景不透明度与反差 | opacity 约 0.10–0.35、反差约 10%–35%、阅读区较干净 | 以文字与图表可读为准；不要求固定中心空区 |
| 段落长度 | 约 110 字／7 行；180 字／10 行以上重点复看 | 优先精简、分组或拆页；不因字数单独判失败 |
| 字号与层级 | 正文约 18 pt；标题、目录按观看距离放大 | 依据投影、屏幕或阅读用途实际检查；文字溢出、不可读仍需修复 |
| 裁剪、装饰与导航尺寸 | 参考页与 qa_rules.py 中的比例 | 主体、数据、文字与导航是否完整；几何风格不靠数值判美观 |
| 同风格主色距离 | qa_rules.py 的配色距离阈值 | 是否保留同方向核心底色与配色语义；局部明暗、辅助色、事实图可有合理差异 |

特殊分块最少页数floor(N/2)+1及占位框默认12%／满足修订记录条件后15%的比例容差属于既定约束，不由审美复看提示覆盖；后者仅按[有限放宽规则](preview-contract.md#多次比例修订后的有限放宽)执行。

16:9／1920×1080 输出规格、图片不得拉伸、文件哈希、材料身份、准确文字、对象完整性与批准状态属于技术和真实性约束，仍按各自契约检查，不属于上述审美提示。

### 分块说明与风格要求的分工

设计稿与提示词都要交代特殊分块：风格要求概括实际采用的造型语言，分块说明记录形态、内容归属、相邻关系与阅读顺序，二者互补，不重复整段。斜切、弧线、扇形、同心圆、波浪、金字塔、放射、左圆右栏、六边形及创意组合均可按内容调整，不要求照搬参考图。轮廓、曲率、局部比例、间距和装饰细节允许模型发挥，以可读性与内容逻辑优先；事实图片比例和既有内容要求仍须落实。

文本框形状、填充、描边、文字配色与字体层级集中在风格要求中按角色或适用范围说明一次，不逐框重复，也不移到排版树父节点重复。排版树的文字条目只说明具体文案、文段类型、位置和文本关系；图片及其他图形仍交代实际内容、位置与必要结构。文本框样式与宏观特殊分块形态要区分，后者在分块说明中保留。

### 同风格底图的核心底色与文字预留

封面与目录底图的构图提示：主体区与文字留白区用边界线划分，直线、曲线或其他线形随所选风格与局部构图选择，不侵入阅读区。仅作生成提示，不作为提示词或图片检查项，不因未采用而否决图片或阻止选择。内容页背景不强制套用。

同一设计方向的封面图（hero-image）、目录图（toc-image，启用目录时）与内容页背景图（content-background）必须保持一致的核心底色。先确定该方向的背景基底主色、冷暖与明暗基调，在这三类图的实际提示词中沿用同一个具体底色说明；使用色值时沿用同一色值。主体对象、辅助色、局部光影和纹理可以不同，但不能仅保留相同强调色却把背景基底换成另一套颜色或明暗基调。不同设计方向仍可采用不同底色，不要求各图逐像素同色，也不以整图平均色或固定色差阈值替代实际判断。

生成封面与目录底图前，根据候选文案及预计排版位置，为标题、副标题、汇报信息或目录条目预留足够的连续阅读空间；位置和范围按实际文案体量决定，不固定在中心，也不设统一留白比例。每条实际底图提示词写清预留区域的大致位置及文字用途，要求主题主体、轮廓线、装饰线条、弧线和强光效避开该区域，不穿过或侵占文字将要排入的空间。预留区保持平静、对比稳定，不提前生成文字、文字框或占位框；内容页背景图同样不干扰计划阅读区。生成后按方向并排查看核心底色，并结合预计文字布局检查留白是否够用；问题通过图生图调整局部构图，不靠压窄文字区或缩小文字迁就底图。

### 底图生成的复杂度与视觉主次

底图复杂度与主次作为内部设计参考，不要求在实际提示词中复述“不要过于复杂，不要抢夺视觉中心”“细节简洁”“纹理与光效克制”等通用句子。实际底图提示词只写用途与16:9尺寸、视觉风格和可用颜色、具体材料主体、主体位置与文字留白、必要禁项，通常100–220字，不设凑字数下限；有明确额外细节时可合理加长，不截断用户要求。

主体来源与全篇代表性在内部规划时核对，绘图指令直接写已选对象，不重复材料筛选、事实边界或验收说明。封面和目录只用一个具象主视觉占满预定视觉区，可配少量主题点缀，主体区与文字留白区以边界线区分（仅提示，不检查）；内容页背景将主题元素以低对比置于边角。保留已选方向的底色与页型阅读区，不生成文字、数字、图注、文本框或图片占位框。初次生成、换风格重生与自然语言改稿采用同一简短口径，已确认图片和人工提示词不因规则更新自动重绘或替换。

### 学术与创新创业场景的文本框处理

学术汇报或学术答辩中，文本框内部尽量采用均匀、平整的填充，尽量不要使用渐变。装饰色块内部不使用渐变，采用平整填充，保留清晰边界；色块之间可以用渐变表示真实的递进、关联或过渡关系，渐变位于块间连接或过渡区域，不作为色块内部填充。分标题采用有底色的文本框时，应与正文文本框有明显、可辨认的色差，区别层级；不限定色值或色差阈值，无框文字不因此被强制套框。

以上要求作为设计与实际看图检查的参考，留在规范库。实际生图提示词仅说明页面可用的大致颜色，不逐项指定标题、正文或图注颜色，不附加深底浅字、简约、紧密排版与可读性等通用条文，不要求逐字复述规范。具体配色用途由生图模型结合主题与局部画面安排，重建时按预览中的实际颜色还原。已有底图视为锁定背景层，只在其上新增文字、图片占位框与必要图形，不重绘、改色、移动或改变原有主体、纹理与构图。学术与创新创业用途仍按真实主题区分，不凭“答辩”一词机械套用学术条件。

## Agent 轻量检查

提示词仅检查明确冲突、确认文案与素材身份、占位框数量和比例；普通同义重复和润色建议不判失败。检查未通过时最多自动整理两轮，仍有问题则记录并沿用最后有效稿继续生成，不中止整批任务。

图片只将明显错图、内容遗漏、严重遮挡、不可读、原图损坏和错误内容关系列为必须修正。轻微配色、装饰、留白、对齐和局部构图差异作为建议记录，不触发重生成；academic_fill 和 restrained_decoration 本身不作为否决项，实际遮挡或不可读仍需修正。图片占位框比例是重点约束，不随审美检查放宽；提示词在内容、排版、配图三处强调具体宽高比。比例偏差在 5% 内直接等比贴回原图，超过时最多修正两次。
