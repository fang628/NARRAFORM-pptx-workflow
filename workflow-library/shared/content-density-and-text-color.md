# 信息密度、内页逻辑与文字配色

本文件贯穿内容选择、设计稿、三版方案、全篇预览、元素重建与成品验收。忠实于材料、信息完整优先，其次为页内逻辑与可读性；文字颜色仅提供设计建议，不是必须遵守的标准。

## 内容与设计稿

- 上屏关键结论必须用一句完整的话说明，可由结论型页标题或一个正文项承载，避免重复；封面、目录等不强加结论，不补造材料不支持的判断。其余语段可用短语与短分点，不必写成完整句子。数据优先采用“指标/条件 + 数值 + 单位 + 对照或变化”的紧凑表达，保留比较口径与限定条件，不用完整叙述句铺陈每个数值。
- 每个字段只承担一个信息单元：小标题建议6–16字，正文项建议15–45字、尽量不超过60字，图注建议10–35字；主标题不超过28字，副标题不超过40字，关键结论同样简洁。长项在内容阶段去掉赘述，按语义将论据、条件与解释拆成短子项并分别关联来源；不切断术语、公式、数值与单位，不丢失必要限定。用户明确保留的原文或完整引用优先，讲稿不受上屏短字段建议限制。已确认文案在后续阶段完整还原，长度建议不作为重建或验收的阻断检查。
- 逐页规划时先逐组匹配材料中的相关图片，再组织短文案；能支持观点、解释步骤或展示结果的图片实际插入内容树，积极使用互补多图、步骤配图与局部细节，与对应小标题和正文紧邻。优先原图、文档提取图、人工裁片及已有补充图，不限普通内容页只放一图，不为凑数重复或插入无关图，不虚构证据；封面与目录尊重已确认配图设置。
- 在材料有依据且字号清晰可读的前提下，提高每页有效信息密度。逐页写出充分的最终上屏文案，按需包含问题、方法与条件、关键证据、结果及解释或限制；封面和目录按页型处理。不强制每页都具备同一组模块，不用重复句子、装饰或虚构内容填满画面。
- 内容精简应去掉赘述，保留支撑论点所需的条件、比较口径与结果；信息多时先优化分组、图文比例与空间利用，不靠缩小字号或扩大空卡片来达成密度目标。
- 内页必须体现页内逻辑，逐页写清流程、递进、对比、层级、并列或中心与支撑关系，说明读者先看什么、如何读证据、得到什么结论。用分块、共同对齐轴、编号、箭头或同尺度对照表达真实关系；不能把并列观察画成因果，也不把所有内页固定成三段文字加一张图。
- 分块选择按[设计判断与检查提示](design-principles.md)执行，写明版式如何服务内容关系。设计稿在风格要求中集中记录角色字号，排版树记录大致位置、相对大小与对齐，不记录坐标或精确宽高。

图片数量与尺寸不作为减少分点的理由；先优化图文比例、阅读层级和空间。文本节点的label是编辑标识，不是小标题，不可据此补造文案；实际小标题仅取自内容树的分组或明确文案。

## 段内符号与排版结构

上屏文本段内尽量避免用箭头和冒号串联信息。把“标题：说明”拆成独立小标题与正文，把“步骤A→步骤B→步骤C”拆成独立步骤或递进分块，用位置、分组、对齐和层级表达关系；确有流程连接需要时，可在文字对象之间使用独立图形连接线或箭头，不将箭头字符嵌进正文串。

这一要求针对上屏文案，不针对设计稿或提示词的Markdown字段冒号。科学公式、反应式、比例、时间及材料中必须保留的符号按内容含义处理，不机械删符号。设计阶段完成拆分与精简，独立标题和正文同步登记到content.json；提示词带入定稿文字及实际结构，不能让生图模型自行改写已确认文案。生成后核对结构是否落实，避免重新合并成带冒号或箭头的长段。

## 文字配色建议

- 深色阅读区必须使用白色或浅色文字，浅色阅读区使用黑色或深色文字。按文字所在区域的实际底色（包括文本框、卡片填充）判断，不以整页底色代替；强调色也须保持清晰可读。
- 生图提示词只列页面可用的大致颜色，如深蓝、灰白、暖黄，不为标题、正文或图注指定颜色，不要求精确色值。精确色值保留在内部风格登记、元素清单与PPT重建数据中。
- 标题、副标题、正文、图注、编号、页码与导航可按主题、品牌和层级选择其他颜色。可使用彩色文字；同级保持清楚一致的语义，不因采用彩色、整段主题色或全篇彩色文字而单独判定不合格。
- 红色或黄色可用于关键数据的局部强调，也可选择其他强调色；强调对象可以是数据、关键词、小标题或导航状态，由内容需要决定。建议控制竞争性强调，避免削弱主次关系，不限制必须采用红黄或只能强调数据。
- 设计稿记录页面可用配色，不逐项规定文字颜色；元素清单记录预览中实际观察到的颜色，成品按已确认预览还原。原始事实图片、图表内部已有颜色保留原件，不为统一文字配色改写图中信息。

## 预览与成品落实

阶段 2.1／2.2 的提示词在内容要求中保留充分文案和语义角色，在排版要求中写清逻辑与阅读顺序，在风格要求中仅列本页可用配色，由生图模型安排其用途；不附加深底浅字、简约、紧密排版或可读性等通用套话。不要把黑白主色、红黄强调或避免全篇彩色改写成每页必守条文；共享样式描述一次，不把设计稿字号或坐标塞进提示词。

逐页实际看图时核对有效信息、条件与证据、逻辑、字号、留白，以及文字与实际背景的对比、层级和阅读效果。颜色种类与是否符合上述推荐不作为否决依据；出现难读、主次不清或颜色语义混乱时才按实际问题修订。元素清单记录实际配色与局部强调，成品用原生文本或文本片段还原已确认设计，修订后复看。
