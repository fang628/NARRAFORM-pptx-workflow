# Agent 返回编辑、复用与修改历史

可在03/04/05返回前序步骤继续编辑，不强制全部页面确认后才能生成视觉方案；仅为已确认页面生成。前置更新后，后续可以跳过重生成，复用原布局与图片并同步新文案，仍明确提示需核对的差异。

修改一页优先影响该页；共同材料或风格变化时按实际依赖扩大范围，不无条件重生成全套。03代表页直接复用到04，全篇预览不另放重新生图按钮，图片修改走统一弹窗。

03可重新选择“简约平面”或“写实／立体”，先重新规划风格与提示词，再由用户确认生成。旧风格、提示词与底图保留历史；规划失败时保留原选择与结果，不清空02内容。

AI提示词与单图编辑均可撤回；05只提供单页撤回，修改结果覆盖该页对比位置，不新增重复展示区。框选仅提示区域，结合描述定位和补拆目标，不将框当硬裁切边界。

检查、接口或JSON错误应定向修复，保留已经完成的正确结果，不盲目重复整批请求。失败记录和图片保留；达到有限修订次数后展示最后可用版本与问题，允许继续和下载，不伪造通过结论。
