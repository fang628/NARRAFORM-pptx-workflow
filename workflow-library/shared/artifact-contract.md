# Agent 阶段与素材契约

本文件记录本地网页Agent当前流程，不要求执行原始skill的命令行状态机。项目真实文件位于data/<project-id>；图片、任务、来源、修改历史与几何参数由项目JSON和阶段记录关联。内部编号不上屏、不发给生图模型。

## 阶段边界与返工路由

| 网页步骤 | 工作内容与结果 | 进入后续的依据 |
|---|---|---|
| 01 需求与材料 | 接收文件、文件夹、文字，提取文字/表格/公式及原图，理解材料并保留细粒度原文索引；人工裁图不覆盖原图 | 保存需求，确认材料理解 |
| 02 逐页内容 | AI先生成多层内容树与单页设计稿，用户修改并逐页确认；可生成补充图片 | 任意已确认页可进入03，不强制全页确认 |
| 03 视觉方案 | 选择可重选的表现类型，规划三方向风格、预设配色及底图提示词；确认后生底图，再由用户点击生成代表页 | 选择可用方向，允许接受检查问题 |
| 04 全篇预览 | 复用代表页，为其余已确认页面基于对应底图图生图；先处理占位框再插回原件 | 确认完整预览；检查问题可明确接受后进入05 |
| 05 导出交付 | 元素审计、素材重建、可编辑PPTX组装、渲染对照、有限修订与下载；可选生成讲稿PDF | 展示实际结果和剩余问题，不另设release批准栏 |

底图不在01自动生成；未启用封面/目录时不强制补相应底图。不在后一阶段开头才运行前步的审美检查并中断工作。前置内容改变时可返回编辑，也可选择跳过重生成、沿用原布局图片并同步新文案。

## 素材身份与原材料陈列

“已收到的材料”仅展示原始材料、编辑后的原始材料及AI补充图片；重建提取素材不混入原始材料陈列。裁片与原图分别登记，裁片重理解后沿用普通图片插入路径。

图片节点有独立材料身份，可编辑图注从属于图片，不另加重复正文图注。原文引用保留可定位位置及文档格式，多次引用同一段原文时界面合并显示；无效引用定向修复并保留有效结果。

## 原始底图／登记底图素材

hero-image、toc-image、content-background是03按方向生成的无字背景，依启用页型使用。完整预览锁定对应底图，在其上新增信息；最终PPTX使用该底图作为背景。事实原图另行登记、占位并贴回，不从AI预览复制近似图代替。

## 从预览到可编辑重建

- 简单色块、线条和常规几何：PPTX原生图形。
- 简单平面图标、复杂矢量形状：SVG重绘，验证后使用。
- 复杂现实风格图标、复杂画面元素：优先图生图抠图，可结合本地精确提取；框选只是目标提示，不是硬裁切边界。
- 原始照片与事实图：使用登记原件，沿用确认的显示几何。
- 文字：准确文案作为原生独立文本；留意字体、字号、填充框与框形，小标题与正文分开，目录编号与条目、小标题中的编号分离，不能合并成一段。

重建检查还需观察底图未包含的色块、复杂视觉、叠放和页面美观度，尽量接近确认预览。拆出的素材可查看并提出增删意见；支持指名元素修改与大致框选补拆。单页修改覆盖对应对比位置并支持单页撤回。

## 修改、检查与交付

图生图小修改只发当前调整意见；文生图重绘只发用户确认的完整最终稿，两者不拼接历史。自然语言整理是可选项，统一单输入框，单图可撤回。

所有生成结果与失败记录保留；检查解析或接口失败不等于图片本身错误。05实时展示每轮结果，多次修订后仍不理想时展示最后可用版本并提供下载，不隐藏已完成页面。

下载栏先提供PPTX，讲稿PDF明确标为讲稿且按需生成。不同PPT页的讲稿以编号和标题分点，PDF连续排版，仅纸张满时自然分页；不按每张幻灯片强制另起PDF页。不提供单独检查记录下载栏。
