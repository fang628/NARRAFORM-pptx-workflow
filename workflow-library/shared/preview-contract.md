# Agent 底图、预览与原图贴回契约

## 画布与素材

整页请求16:9，优先1920×1080，接受较小的16:9图。供应商像素取整导致的比例误差不超过0.5%时，可等比缩放并以边缘像素补足微小留边，保留完整画面；不裁切或拉伸整页。最终网页预览统一1920×1080。局部素材与原始材料保留自身尺寸，不受整页比例限制。

## 封面与目录的原底图构建

底图在03生成提示词、用户确认后生成；按需求启用封面与目录，不要求未启用页型的底图完整性。一个页面的生成任务只发送对应的一条提示词。主体是符合主题、贯穿全篇材料共同主线的艺术表达，不要求材料实物。任何风格的封面与目录在主体、形状或视觉效果上至少一项不同，各方向全套底色一致。

封面主体区与留白区的边界线仅作提示，不检查。目录文字区连续留空，不画文本框或条目；内容背景边角低对比主题元素、中央大片留空，不分框或预设内容排版。底图不包含文字、数字、图注、文本框或图片占位框。

封面和目录默认不额外插内容图片，底图不作为内容树图片项或图注对象。用户明确登记的额外内容图片仍按身份独立占位、贴回。

## 对应底图图生图

03三方向代表页及04全篇预览必须附上对应底图，用图生图在其基础上构建信息，保持底图颜色、结构、装饰和排布不变。底图要求只写这项继承，不再描述其画面排布。底图在最终PPTX中作为对应页的背景。

风格预览的代表页直接复用到04，仅生成其余已确认页。只确认部分页面也可生成这些页的方案，之后可以返回前序步骤继续修改。

## 占位框、定位与身份

登记原图一图一无字平坦占位块，不额外多画；在提示词的内容、排版、配图三处保留具体宽高比，并在配图项写宽×高像素尺寸。比例误差阈值属于检查，不塞入绘图提示词。

通过节点与材料身份映射、模型位置规划和本地视觉边界定位确定对应框，不用原图宽高比猜测匹配关系。实际框的精确位置与尺寸保留在本地计划，不把粗略AI位置直接视为最终边界。

## 多次比例修订后的有限处理

先看占位框比例，再贴原图。相对登记图片比例偏差超过2%时最多修正两次；仅发送本轮需要修正的比例、位置或尺寸问题，不附原提示词、完整设计或修改历史。偏差很小或已达上限后继续合成，不无限重生成。

原图显示比例允许相对原件5%以内的轻微调整以贴满框，超过时完整等比放入。仅改变显示尺寸，不裁切、重画或覆盖原始文件。预览与PPTX使用同一位置、尺寸、适配参数，保留原件身份与哈希。

贴回后的自动修正只能调整图片大小和位置，并受对应框约束，不让整页生图模型改动文字、底图或其他对象。

## 预览检查与继续

本步结束记录实际问题，04界面只显示问题，不输出泛泛通过说明或建议修改提示词。轻微审美差异不反复重生成；检查接口失败也保留图片与记录。

检查未通过仍可选择方案，明确确认后可进入05。05按预览拆解、重建、渲染对照并有限修订；达到修订上限仍展示最后结果并提供可用下载，保留问题说明，不用单独release批准栏阻止交付。
