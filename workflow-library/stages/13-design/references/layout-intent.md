# 版式意图与阶段边界

版式分类、几何示例和风格令牌是参考，不是强制模板。优先依据本页实际关系选择或创造结构，不能为了归类更改内容。

## 02 内容与设计稿

AI按材料先生成逐页文案与多层内容树，再写单页设计稿。节点顺序、从属与并列以内容树为准，文本标签不上屏，不据此新增小标题。主标题恒为最高项，副标题仅附属主标题；各段、分点与实际小标题分别保留。

设计稿只给宏观组织、主要阅读方向、大致位置、相对大小与粗略创意，局部形状和组合保留发挥空间。小标题对齐对应正文，多图紧邻所属内容。内部估计图片的最小可读尺寸，不因图片数自动减少分点或遗漏文字。

## 03 风格与底图

先选择可重新选择的表现类型，再规划风格与底图提示词。完整预设与仅借配色分开处理；简约平面可以优先借用合适预设配色而不继承其写实装饰或字体。所有新设计登记后用于生图。

底图不是排版稿：目录文字区留空且无文本框、条目；内容背景中央大片留空，不画分框或构图骨架。艺术意象须符合主题并贯穿全材料主线；各方向全套同一底色，封面与目录在主体、形状或视觉效果上至少一项不同。

## 03/04 整页预览

一页一张整页设计，使用对应底图图生图，底图颜色、结构、装饰、排布不变。内容项用多层列表表达完整文案与归属；排版项只概述主要关系和粗略创意，不逐框规定细节，不在风格项重复。

登记图片身份与节点固定，按已规划尺寸和比例占位。占位框比例重点检查，最多两次修正后贴回原件，不用图片比例猜测身份。预览给出插图后的成品；03代表页直接复用到04。

## 05 元素重建

精确位置、尺寸、字体、字号、颜色、框形、层叠与素材来源在此落实，不把这些工程参数变成长生图提示词。主标题、副标题、小标题、正文、目录编号分别作为可编辑对象，不能合并。只重建预览实际存在的元素与登记背景。
