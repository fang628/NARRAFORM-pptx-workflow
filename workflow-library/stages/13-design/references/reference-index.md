# 用户参考页索引

这份索引仅保留历史归纳的来源文字记录，参考 PPT 图片与联系表不随 Agent 分发。

原始参考文件不在项目规范库中；生成时仅使用文字规范与风格令牌。

此处75张是旧稿风格／结构参考，新增特殊分块图另见[分块参考库](layout-splits.md)，两库分别计数。

共 75 张：封面 11 张、目录 10 张、其余页 54 张。全部为精确 16:9。

阶段 2.1／2.2 选型直接使用[参考分类库](reference-categories.json)；它按页面类型、版式、风格和题材归纳全部 75 张参考，并给出版式意图、计划图片区域与结构转写提示。
