# Agent 风格与配色指南

本文件是项目内当前风格口径。原始风格令牌保留用于完整预设复用，参考 PPT 图片已移除；文字版式与几何示意仅作设计样例。网页的工业风、黄黑灰白、等高线、点阵与电路线不构成 PPT 默认风格。

## 风格与配色的选择

1. 在03生成底图提示词前选择“简约平面”或“写实／立体”，可重新选择。底图与后续预览沿用所选表现，不混写两种要求。
2. 简约平面用抽象意象或具象对象的图形、色面、轮廓与留白；写实／立体用材质、体积或自然光影。两者都允许有设计感的组合，不把艺术主体等同于必须材料实物、照片或3D。
   - 简约风格标题与正文采用简洁黑体或无衬线体，避免书法体、毛笔字和手写体。含书法字体的预设不整套继承，可只借合适配色，另行登记平面设计；预设库原件不改写。
   - 简约风格的封面与目录底图须有明确且贯穿全篇主题的主视觉，轮廓清楚，以足够尺度和适度层次使视觉区相对丰满；避免小图标或零散装饰代替主体。保留连续文字留白，不用无关元素填满画面；封面与目录继续在主体、形态或视觉效果上有所区别。内容背景仍在低对比边角放主题元素，中央大片留空。
3. 完整采用预设时，用 referenceStyleId 引用 A–F：先按材料主题、用途、受众及表现类型判断，不能只因配色好看、名称相似或换上主题主体就认为相符。符合主题且与用户选择不冲突时优先采用并原样复用；均不适合或用户明确另选时原创。指定参考也不能绕过主题适配。
4. 简约平面另行评估预设配色。字体、装饰或写实表现不合适，不妨碍单独采用符合主题的配色：填写 paletteReferenceId，referenceStyleId 留空。只复用底色与颜色，不继承渐变、字体、字效、框形、图片处理或版式；平面设计登记为新风格，并记录配色来源。
5. 完整预设不新增项目登记，不擅改其设计；仅替换材料内容与主体。原创或配色借用后的新设计需登记名称、适用理由、配色、字体层级、框形、装饰与版式，变化后登记新版本。
6. 同方向封面、目录、内容页使用同一核心底色，覆盖原预设按页型换底色的旧做法。三方向主色尽量来自不同色系；不能为凑色差选择不合主题的预设或自动修改预设颜色。三种方向可以采用同一合适预设。
7. 重新选择时先规划新风格与提示词，确认后生图；旧底图保留历史，规划失败保留原结果，不自动清空02内容。

## 底图与整页的边界

03按确认页型准备封面、目录及内容背景提示词。封面与目录采用符合主题、代表全篇材料共同主线的艺术化主体，可抽象或具象，不要求材料中存在对应实物。所有风格下，封面与目录在主体、形状或视觉效果上至少一项明显不同，不只挪位置或镜像。直接描述艺术意象，不选只代表局部小节的意象。风格名称留在网页与登记中，不发给生图模型。

底图只承载主题画面与留白，不生成文字、编号、图注、文本框或图片占位框。目录文字区连续留空；内容背景只在低对比边角放主题元素，中央大片留空，不预画分框、卡片、分栏或分隔线。完整预览用对应底图图生图，保持原底图颜色、结构、装饰和排布不变，在其上构建信息；PPTX将对应底图作为背景。

## 版式与文案

版式库只是样例，可以创造新结构，不强制套版式编号或从有限菜单二选一。真实内容关系优先：多层列表表达从属与并列，主标题恒为最高项，副标题仅附属于主标题。文本节点标签只是编辑标识，不是上屏小标题；不从标签补造文案。

有并列信息时分点独立排布，小标题与对应正文对齐，不把小标题和正文合成一段。适合时积极采用有表达作用的特殊分块和图文组合，只给单页粗略创意意图，局部造型由生图模型发挥；不设特殊分块页数配额，不作为检查否决项。

具体阶段用法见[提示词口径](gen-prompt-scope.md)、[版式意图](layout-intent.md)和[设计原则](../../../shared/design-principles.md)。
