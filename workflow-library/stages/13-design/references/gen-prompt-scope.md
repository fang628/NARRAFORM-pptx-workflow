# Agent 生图提示词口径

本地 Agent 仅使用本文件当前结构。内部规划、检查阈值、历史规范与风格登记不整段复制给生图模型；用户确认的最终稿作为单一执行稿，不叠加旧提示词或修改历史。

## Agent 七项分点结构

1. **比例要求**：当前页型、仅本页、16:9（优先1920×1080）。一次不写三页任务，不生成多页拼图。
2. **内容要求**：以多层嵌套列表逐条写实际文案与归属，同级信息分别独立列出；是否连接按文段语义确定，不从列表顺序推断因果。标题、附属副标题、实际小标题、正文、图片及图注保持归属，不把编辑标签当小标题。
3. **排版要求**：主要分组、大致区域与阅读顺序；保留预设原版式，不重复风格项的创意设计段。不逐框限定形状、位置、对齐细节，不贴“实际排版要有创意”等编写口号。各段、分点及小标题与正文独立排布，内容关系不变。
4. **底图与配图要求／图片占位框比例**：使用对应底图图生图，保持原底图颜色、结构、装饰和排布不变，在原底图基础上构建信息。不重新描述底图排布。登记图片一图一无字平坦占位块，不多画；逐图提供比例及已规划的宽×高像素尺寸。
5. **风格要求**：写所选具体表现方式、页面可用的大致颜色及必要字体、承载、图形语言，并包含一句针对本页的“创意设计”：参照特殊分块规范，结合文段关系、文字量与图片空间判断，适合的方向必须采用，并写成明确的特殊分块、异形承载或图文组合指令，不能弱化成可选或探索建议，以疏密和尺度变化建立重点；斜切与弧线也作为正常候选，分别可用于对照分隔、历程串联或中心围合；不罗列全套例子，不细锁局部构图，完整预设沿用原有分块与框形。不写风格名称，不逐项指名标题、正文或图注颜色，不堆材质、光影或通用美学条文。
6. **进度条要求**：按需求启用，位于页顶且仅一条，全篇共用01中可编辑的4–6段章节名称，多页可归属同段，仅突出当前章节，不按每页设置节点；封面与目录不显示。已经说明的要求不在其他分点再叠加。
7. **视觉关系要求**：只用自然语言说明哪些具体内容之间添加哪种箭头、表示什么联系；不另设起止点登记，不添加通用连接原则。基于文段的实际流程、递进、因果或回指反馈来安排连接，并列不连箭头。没有实际连接时写“不加箭头”。

每张登记图片的具体宽高比可在内容、排版、配图三处强调，这是保留的关键约束，不当作冗余删除。除此以外，共同要求只写一次。每张图片仅有一个图片标题（role=imageTitle）或一条图注（role=caption），不能同时存在，不重复补写。二者在列表中直接从属于图片；图片标题紧邻图上方，字级或承载区别于分组小标题，不用group承载；图注在图上方或下方。已有其一时不另造另一项或同文正文。

## Agent 配色与风格

03选择“简约平面”或“写实／立体”，后续底图与预览统一沿用。简约平面优先选择符合主题的预设配色，可以只借配色，不继承不合适的写实装饰、艺术字或卡片版式；完整预设与仅借配色分开登记来源，见[风格指南](style-guide.md)。

实际提示词只列页面可用的大致色名，不发送精确色值、预设名称或登记名，不为文字逐项分配颜色。精确颜色留在内部风格登记与重建数据。原有底图固定，信息层可按内容关系发挥。

不另列原图保真、简约、紧密排版、可读性等分点；不追加“承载干净”“文字区安静”“深底浅字”等通用条文。内部看图仍须判断局部底色与文字的对比；缺少这些原句不是提示词缺陷。

## Agent 画面表现与无字背景

底图通常为100–220字单段，仅写用途与尺寸、具体表现与可用配色、明确的主体对象名、位置与留白、必要禁项；不扩写主体结构、构象、材质参数或筛选依据，不设置凑字数下限。

- 封面：一个符合主题、代表全篇材料主线的可辨识主体对象占据视觉区，文字区连续留白，可有少量主题点缀。主体与留白的边界线仅作生成提示，不作为检查项。
- 目录：沿用本方向底色，主体、形态或视觉效果与封面至少一项不同，目录文字区连续留空，不生成文本框、条目、编号或区域分框。
- 内容背景：共同主题元素仅在低对比边角，中央大片留空，不画分框、卡片、分栏、分隔线，不预设信息排版。

三种用途分别保存，一次只提交当前用途的一张。仅封面底图提示词须以“主体：具体对象名”说明PPT实际介绍的核心对象，再简写一两项鲜明辨识特征；内容背景不要求主体字段，仅写装饰与留白，不用“同一主体”等代称。底图不含文字、数字、图注、文本框或图片占位框；生成后展示，不自动审美检查或自动改图，再由用户点击进入三版预览。

## 全部文本框与图形元素的逐项说明

这是内容完整性的要求：内容项按节点保留全部准确文案与多层关系。排版项只概述主要分组和阅读路径，不逐个重复正文，不要求逐框细节。字段标签、工程编号与内部检查记录不上屏。

不得发送元素坐标、具体字号或文本框精确尺寸；画布尺寸、登记图片占位框宽×高像素尺寸、图片比例及材料中的科学数字是例外。比例误差2%属于本地检查阈值，不写进绘图提示词。

## 修改与检查

图生图小修改直接发送用户当前输入的自然语言调整；AI整理是可选操作，结果直接回填同一输入框。框选只是定位提示，不是裁切边界。不附原提示词或完整设计。文生图重绘先由用户或AI改好完整提示词，确认后仅发送最终稿，不混入旧稿，不使用原图作为编辑源。两种修改保留单图撤回。

提示词检查只检查明确冲突、内容与素材身份、占位框数量与比例等关键要求；失败时定向修正，最多两次，仍不能确认则保留最后有效稿并记录问题，继续执行。占位框生成后的本地检查与修正见[预览契约](../../../shared/preview-contract.md)，不得与提示词编写要求混淆。

简约风格规则写入现有“表现”或“风格要求”字段，保持模板原有分段与顺序，不另增背景规范、页内元素规范等长段落。

仅封面明确一个具象主体，须为PPT实际介绍的核心对象，保留鲜明辨识特征，可有少量陪衬；不得以普通物件、泛化雕塑、配色、氛围或光影替代。内容页背景不要求主体。该要求用于规划与发送前提示词整理，不新增生成后图片验收。


封面主体是核心主题的艺术化表达，不要求写实复刻。先理解材料对象与特有关系或能力，再形成一个鲜明可画的艺术形象；不默认使用单张页面、玻璃面板、通用界面或普通物件。材质不代替主体特征；文稿与软件题材可将其特有能力作视觉转译，不机械复刻空白窗口，也不把同一文稿图层模板套给所有题材。实际提示词只保留所选形象和一两项可画特征，不出现“登记原图”“原生形状”“仅表现框位”等程序术语，不预画空文本框或图片占位框。目录与内容背景不继承封面的主体限定。

底图提示词须明确让出的区域：写出左侧、右侧、中上部或中央等方位，以及大致范围或面积，并让主体与装饰避开该区；不能仅写“标题区留白”“目录区留空”或“适当留白”。封面按标题与副标题、目录按目录文字、内容背景按中央信息区分别描述，不能混入其他页型；已采用预设的阅读方位保持原设计。不画留白区边框、条目或占位框。该要求不扩展为整页预览提示词中的背景排布描述。
