# Agent 05：独立元素重建

本步骤在网页05执行，不运行原skill的目录型命令或状态机。以确认预览、准确内容树和登记素材身份为依据，使用用户配置的模型通道。通用边界见[阶段与素材契约](../../../shared/artifact-contract.md)及[预览契约](../../../shared/preview-contract.md)。

## 方法选择

- 简单色块、线条、常规箭头和规则几何使用PowerPoint原生图形；保留填充、描边、阴影、线宽、端点、方向与渐变。
- 简单平面图标、复杂矢量轮廓用SVG重绘；必须有有效viewBox，不含script、foreignObject、外部链接或嵌入位图，完成XML和实际渲染验证。
- 复杂现实风格图标、复杂画面用图生图抠图，优先独立透明PNG。透明输出不可用时本地分离并验证透明度；不把普通矩形裁片冒充精确抠图。
- 事实图片使用登记原件及确认的显示几何，完整铺满对应占位框，允许拉伸，不裁切或改写原件，不用生成图替代。
- 对应登记无字底图直接作为PPT背景，不重复提取其主体和装饰；不得把含文字的整页AI预览作为背景叠字。

## 文字与导航

准确文案以独立原生文本对象重建，保留字体、字号、粗斜体、描边、阴影、渐变、承载框及框形。小标题与正文、目录编号与条目分离，不合并多段文字；用实际渲染检查溢出与可读性。文字和简单色块渐变使用PowerPoint原生渐变，不转为位图。

统一进度条由程序生成，不提取旧预览导航。箭形横列（首项扁六边形）或气泡横列均带渐变、轻阴影、细描边；4–6个章节按文字量自适应，当前章节放大加粗。封面、目录无导航。动画采用立即换页的章节滑动及文字平滑变化，其他对象与底图淡入淡出。

## 复用、修改与交付

相同元素复用已成功重建素材，记录来源、哈希和用途，避免重复生图。只修改非事实视觉，不能重画原始证据。框选只是位置提示，结合周边识别完整对象，不把选框当作硬边界。

素材按页展示，支持指名修改、增删意见、框选补拆、单页重试及单页撤回。失败时仍展示已完成元素；修改直接覆盖对比位置，不增加重复结果栏。重建素材不进入“已收到的材料”。

组装后必须实际PowerPoint渲染并与预览对照；注意准确文字、字号、框形、底图外新增色块、复杂视觉和叠放。有限修订后仍有视觉偏差时展示最后完成的结果并提供可用PPT下载；结构或哈希不一致时不可下载，不另设release批准步骤。
